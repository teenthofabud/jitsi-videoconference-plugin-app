How to Install

TOAB Jitsi Plugin works inside the calendar you already use. Choose your calendar below to see how to install the plugin and add Jitsi meetings to your events.

Google Calendar

Install the add-on from the Google Workspace Marketplace.

  1. Open TOAB Jitsi Plugin in the Google Workspace Marketplace and click Install.
  2. Sign in with your Google account and review the permissions. Our Privacy Policy explains what each one is for.
  3. In Google Calendar, create or edit an event and choose TOAB Jitsi from the video conferencing options.
  4. To use a different Jitsi server, open the TOAB Jitsi panel in the event, pick a server and click Confirm Server.

Cal.com

Install the app from the Cal.com App Store.

  1. Open the Cal.com App Store, find TOAB Jitsi and click Install.
  2. Open the event type you want to use and set its location to TOAB Jitsi App.
  3. In the event type's app settings, choose the Jitsi server for your meetings.
  4. New bookings for that event type get a Jitsi meeting link automatically.
